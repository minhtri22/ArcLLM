# TTFT_M2 — Method Transfer Admissibility

## Decision

TTFT_M1 contributes **methodological prior evidence only**. It contributes no mechanism outcome.

The key distinction is:

```text
TTFT_M1 causal design = prior methodological evidence
TTFT_M1 mechanism outcome = NONE
```

## Admissible now

The M1 prior-art register/review, local TTFT path mapping, finite-hypothesis structure, causal-factor vocabulary, 2x2 arm topology, and falsification/STOP logic may be inspected as design precedents.

They are not automatically M2 canonical artifacts.

## Conditional transfer

The M1 2x2 design (`SP`, `SF`, `QP`, `QF`) is only a template at this stage. It was never executed in M1. Before any M2 scientific execution, M2 must independently revalidate source boundaries, factor manipulability, exact target invariants, workload relevance, endpoint semantics, session/order rules and falsification logic.

No M2 package code may silently assume the 2x2 design is already frozen.

## Explicitly non-transferable

The following cannot transfer as evidence:

- support or falsification of H-ART;
- support or falsification of H-DPIPE;
- support or falsification of H-PRECOND;
- support or falsification of H-STATE-INTERACTION;
- support of H-NULL;
- any TTFT-removal intervention result;
- ANL64 P6 timings as M2 confirmatory data.

None of those mechanism outcomes exist in TTFT_M1.

## Governance transfer rejected

M1 activated a strict one-repair budget at an execution-preparation stage before the full runner/lock/result/package composition had been proven closed. That sequencing is not transferred.

M2 replaces it with:

```text
package development
  -> zero-science positive/negative QA
  -> exact package freeze
  -> zero-science governance adjudication
  -> explicit BuildOnly authorization
  -> execution-stage repair budget becomes live
```

## Current consequence

M2 may proceed to implement the zero-science atomic package infrastructure. It may not yet implement or execute diagnostic science, load the target model, dispatch GPU work, measure TTFT, or claim any transferred mechanism result.
